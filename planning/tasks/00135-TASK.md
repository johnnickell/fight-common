# Add Exact Elapsed Durations

## Outcome

Consumers represent and calculate signed fixed elapsed time with exact microsecond precision and explicit checked
conversions. Deliver immutable Duration, direct boundary/arithmetic evidence and documentation in one independently
reviewable PR under [TICKET-00036](../tickets/00036-TICKET.md) and [EPIC-00008](../epics/00008-EPIC.md).

John approved this code-first feature TASK and its contracts on 2026-10-06. It has no TASK dependencies or execution
priority: calendar/zoned/range slices neither supply nor require Duration arithmetic. The additive next-minor scope
requires actual compatibility assessment; planning assigns no exact version or implementation/release authority.

## Scope

- In scope: final immutable Domain/Value/DateTime/Duration with signed integer microseconds, named factories,
  canonical exact string/JSON reconstruction, existing Value/ValueObject/Comparable behavior and explicit conversions.
- In scope: checked addition, subtraction and negation, native-integer bounds, predictable exact-conversion and
  arithmetic failures, deliberate public/behavioral classification, docs/values.md and CONTEXT.md, full verification.
- Out of scope: calendar months/years, wall-clock/DST/calendar-day arithmetic, recurring scheduling, positivity
  requirements for all durations, automatic timeout/TTL adoption, DateTime arithmetic or interval-length APIs,
  Decimal/Money dependencies, floating-point approximation, arbitrary-precision duration storage, new platform floors,
  persistence mappings/schema, unrequested helpers and packaging/release-process tests.

## Validation and permissions

Use signed integer total microseconds from PHP_INT_MIN through PHP_INT_MAX. Document runtime-dependent numeric
bounds without requiring a 64-bit installation or silently casting out-of-range string input to a clamped integer.
Do not accept floats as a substitute for exact representation. Canonical string/JSON must retain the exact signed
microsecond amount and reconstruct it unambiguously; final unit spelling/factory signatures remain routine design
within that promise, not a general ISO calendar-duration parser or source-lexeme preservation contract.

Provide explicit integer-unit conversions, such as seconds/milliseconds and microseconds. Check multiplication
before execution; exact coarser-unit conversion rejects a nonintegral result, including negative fractions, instead
of silently truncating/rounding. No rounding or floating-point result is inferred from a method named as exact.

Check addition/subtraction/negation before an unrepresentable intermediate becomes a float. PHP_INT_MIN is valid as
stored microseconds but its positive negation is not representable. Zero has ordinary numeric identity; zero/negative
values are not universal validation failures. Use same-concrete-type canonical equality/hash and signed numeric
comparison returning -1/0/1. Wrong-type equality is false; invalid construction, exact-conversion/overflow or wrong-
type value comparison raises DomainException. Document representability failures without inventing permission rules.
