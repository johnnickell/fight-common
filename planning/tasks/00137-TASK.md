semantics. Deliver DateRange, direct endpoint/reconstruction evidence and documentation in one independently

## Validation and permissions

Use validated Date endpoints within TASK-00134's proleptic Gregorian years 0001–9999. Require start <= end in Date
ordering; equal dates are a nonempty single-date interval. Containment is start <= candidate <= end, without native
midnight/timezone conversion, implicit time-of-day or step alignment.

Equality/hash captures the ordered endpoint dates and the same concrete range type. Expose stable endpoint access
and unambiguous string/JSON reconstruction that validates both dates and ordering. Malformed/unsupported encoded
endpoints or reversed ranges raise DomainException. Final factory/codec spelling is routine design, not permission
to accept malformed dates, swap endpoints or add arbitrary range caps. No total-order contract between overlapping
ranges is needed or inferred; this TASK owns equality and calendar containment, not interval ranking.
