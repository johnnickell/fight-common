# Reusable Coding Standards and Quality Gates

## Destination

Ship an additive 1.2 quality foundation that publishes the exact opinionated PHP coding standard used by Omphalos, adopts it internally without baselines, enforces Clean Architecture and exact complete statement coverage, and provides a disposable-container build with deliberate dependency-freshness verification.

## Notes

- The coding standard owns rules; each consuming repository owns scanned paths and exclusions.
- PHP_CodeSniffer, Slevomat, and Deptrac remain development tools. Fight Common tests them in `require-dev` and advertises optional consumer requirements through Composer suggestions.
- Fight Common uses one canonical standard rather than base and strict profiles.
- CI resolves latest compatible dependencies. Local dependency updates remain explicit through the build's `--latest` option.
- Implementation must follow the repository submit gate and preserve 100 percent coverage.
- Initial reconnaissance found 524 violations across 137 source files when applying the Omphalos standard; 326 were reported as automatically fixable. This evidence supports the staged migration.

## Decisions so far

- Publish one exact, opinionated `FightCommon` standard derived from Omphalos.
- Migrate existing source in green stages and finish with no baseline, suppression file, or grandfathered violation.
- Require `Domain <- Application <- Adapter` through Deptrac after existing violations are resolved.
- Require exact complete statement coverage; rounded percentages do not satisfy the gate.
- Use one disposable PHP container for the local build while CI runs the underlying commands directly.

## Not yet specified

None at charting. Implementation discoveries that change public behavior return here as explicit planning decisions.

## Out of scope

- Omphalos-specific bounded-context dependency rules.
- Docker Compose wrappers that execute inside an already-running application container.
- Mandatory PHPCS, Slevomat, or Deptrac runtime dependencies for consumers.
- Multiple coding-standard profiles in 1.2.
