# Fight Common Documentation Presentation

## Destination

Make Fight Common's documentation and repository README an engaging, trustworthy product for experienced PHP
developers and architects. Anchor both surfaces in the reusable Fight identity, the approved Atlas Deck
presentation, and capability-led guidance that makes Architecture, Quick Start, and every supported component
easy to find without changing Fight Common's PHP public API.

The completed implementation preserves search, navigation, copyable examples, accessible light and dark themes,
the `/fight-common/` Pages base path, and the canonical grouped routes established at first publication. The
GitHub-profile adaptation remains a separately governed follow-up after the canonical identity assets and live
documentation URLs exist; it does not block this epic.

## Decisions so far

- The closed [Fight Common Documentation Presentation Wayfinder map](../wayfinder/fight-common-documentation-presentation-map.md)
  is the source decision record for audience, information architecture, identity, visual presentation, delivery,
  profile adaptation, compatibility, and quality boundaries.
- Fight Common owns the canonical Fight family mark, Fight Common lockup, documentation, repository README, and
  Pages delivery. The profile repository will own any later profile implementation and publication.
- Retain pinned MkDocs Material and Markdown, implement only narrow repository-owned presentation overrides, and
  deploy an artifact from `main` after the documentation work is complete and John separately approves the
  `develop` to `main` merge.
- Use the approved lightweight quality boundary: fast deterministic pull-request checks, focused human visual
  and accessibility acceptance before initial deployment, and separate hosted Pages verification afterward.
- Keep verification inside the coherent product requirements it proves rather than creating an independent
  testing PRD.
- Implementation, commit, push, pull request, merge, deployment, profile publication, and cleanup remain
  separately approved effects.
