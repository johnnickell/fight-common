# Optional Event Sourcing for CQRS

Ship an additive Event Sourcing foundation that is easier to understand than larger frameworks: explicit aggregates, durable versioned streams, schema evolution, checkpointed projections, and a practical migration path. Existing CQRS behavior remains supported and no consumer migration blocks release.
