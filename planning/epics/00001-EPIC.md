# Optional Event Sourcing for CQRS

Ship an additive Event Sourcing foundation that is easier to understand than larger frameworks: effectively immutable message envelopes, explicit aggregates, durable versioned streams, schema evolution, checkpointed projections, post-commit event publication, and a practical migration path. Existing CQRS behavior remains supported and no consumer migration blocks release.

- PRD-00006 — Integration Guide and 1.2 Release Acceptance

## Progress

The Event Sourcing core now includes the in-memory reference, a Doctrine DBAL Event Store proven on SQLite,
MySQL 8.4, and PostgreSQL 17 with transaction-serialized global ordering, the generic aggregate repository,
and ordered at-least-once projection with stable monotonic checkpoints and explicit rebuild reset. Projection
checkpoints are durable through independently installable DBAL storage proven under lifecycle and concurrent
progress on SQLite, MySQL 8.4, and PostgreSQL 17. Synchronous event dispatch now completes both handler phases and
reports ordered transient failures without suppressing later handlers. Event publication execution, operational state,
and integration branches remain in progress.
