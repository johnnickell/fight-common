# Planning identifier migration

The planning vocabulary changed on 2026-09-14: EPIC remains EPIC, PRD becomes TICKET, and the former executable
ticket becomes TASK. Numeric identities and gaps are preserved. No archived work is reopened by this migration.
Wayfinder decision identifiers (`WF-NNN`) are unchanged.

Use this table when following old PR descriptions, commits, receipts, or bookmarks. Old repository file URLs
do not redirect automatically; the links below identify the current records. Historical external links,
code examples, immutable release receipts, and their validation contracts retain their original identifiers.
Their use of `T-00075`, for example, refers to `TASK-00075` in this repository. Other repositories retain their
own identifier schemes until separately migrated.
