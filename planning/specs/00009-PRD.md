# Build, Dependency, and Coverage Verification

Provide one local disposable-container build contract and an equivalent CI pipeline. CI always resolves the latest compatible dependencies; local builds preserve the current dependency resolution unless the user explicitly selects `--latest`. Both execution models enforce exact complete statement coverage.
