# Components

Use the menu to find a guide by topic, or open the [full list of components](../README.md#component-atlas).

If you use the Model Context Protocol (MCP), start with the [MCP overview](mcp/index.md) or choose a guide:

- [Tasks](../mcp-tasks.md) — Start work that can finish later, and check its progress.
- [Notices](../safe-notices.md) — Keep a record of changes so clients can catch up later.
- [Subscriptions](../mcp-subscriptions.md) — Let clients follow live changes.
